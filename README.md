# Telegram Sender V2

Локальное Windows-приложение для управления рассылками **в Telegram-группы
и каналы, где пользовательским аккаунтам разрешена публикация**.

Проект создаётся заново на основе согласованного ТЗ. Старый репозиторий
используется как источник проверенных адаптеров импорта `.session`/`tdata`,
а два приложенных отправщика — как поведенческие референсы последовательной
отправки. Очередь, база, планировщик и интерфейс реализуются заново.

## Ключевые свойства

- 2–5 аккаунтов, 2–3 активных одновременно;
- одна сохранённая рассылка на аккаунт;
- общие переиспользуемые наборы чатов и шаблоны сообщений;
- создание, переименование, архивирование и удаление групп чатов; массовое
  выделение через Ctrl/Shift, перенос и копирование чатов между группами;
- проверка всех видимых чатов одной кнопкой, красная отметка дубликатов между
  группами и индивидуальное расписание для отдельного чата;
- цветные метки аккаунтов и отдельный статус доступа каждого аккаунта;
- глобальный архив: архивный чат исключается у всех аккаунтов, но не удаляется;
- автоматическая проверка членства и вступление по доступной ссылке;
- два режима цикла: равномерно на весь цикл и быстрый проход;
- постоянная SQLite-очередь без повторной отправки после перезапуска;
- честная обработка `FloodWait`, slow mode и ограничений аккаунта;
- отложенная проверка, что отправленное сообщение осталось в чате; при удалении
  замораживается только этот чат и появляется постоянное красное предупреждение;
- автоматическое вступление или заявка в явно указанный канал-условие с
  повторной отправкой после выполнения условия;
- русскоязычный тёмный интерфейс, трей, автозапуск и уведомления;
- текст + одно изображение, Telegram HTML-форматирование, точный журнал
  фактически отправленного текста;
- произвольные непересекающиеся профили времени суток в МСК: в каждом можно
  задать окно, режим цикла, длительность и случайные задержки.

Инструмент не обходит ограничения Telegram, CAPTCHA, заявки на вступление или
права чатов. При серьёзном ограничении останавливается только затронутый
аккаунт и оператор получает уведомление.

## Разработка

```bash
python -m venv .venv
.venv/bin/pip install -e '.[dev]'
.venv/bin/pytest
```

На Windows используйте `.venv\Scripts\python.exe` и
`.venv\Scripts\pytest.exe`.

## Первый запуск

1. Установите зависимости: `pip install -e .`.
2. Запустите `telegram-sender`.
3. В «Настройки» сохраните `api_id` и `api_hash` для импортируемых
   Telethon `.session`. `api_hash` сохраняется в системном хранилище Windows.
4. Импортируйте несколько `.session` либо папки Telegram Desktop `tdata`.
5. Для `.session` нажмите «Проверить подключение».
6. Создайте наборы чатов, сообщение и настройте рассылку выбранного аккаунта.

Для `tdata` Telegram Desktop должен быть полностью закрыт. Конвертация
использует официальный профиль Telegram Desktop и не запрашивает код входа.

## Windows-сборка

```powershell
powershell -ExecutionPolicy Bypass -File scripts\build_windows.ps1
```

Результат: `dist\TelegramSenderV2.exe`. GitHub Actions также собирает EXE и
прикладывает его как артефакт `TelegramSenderV2-Windows` после успешных тестов.

## Реальная проверка Telegram

Автотесты не отправляют сообщения в Telegram. Перед рабочим использованием
создайте отдельный тестовый аккаунт и приватную/тестовую группу, затем проверьте:

- подключение и тест в «Избранное»;
- вступление по публичной и invite-ссылке;
- одно сообщение в тестовую группу;
- остановку, перезапуск и отсутствие повторной отправки;
- отображение slow mode и ошибки отсутствия права писать.

Не начинайте проверку сразу на десятках открытых групп. Telegram сам определяет
ограничения аккаунта; приложение их не обходит и останавливает аккаунт при
серьёзном предупреждении.
